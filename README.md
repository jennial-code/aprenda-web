# 🚀 Aprenda Web — HTML, CSS & JavaScript

Uma plataforma interativa, moderna e responsiva projetada para ensinar os fundamentos do desenvolvimento web front-end de forma prática, visual e dinâmica.

---

## ✨ Funcionalidades

- 📖 **Trilha de Aprendizado Completa**: Módulos estruturados de HTML5, CSS3 e JavaScript Moderno.
- 💻 **Editor de Código ao Vivo**: Pratique e veja o resultado do seu código em tempo real.
- 🎨 **Design Moderno & Responsivo**: Tema escuro com efeitos neon e tipografia elegante.
- ⚡ **Sem Dependências Pesadas**: Desenvolvido em HTML, CSS e JavaScript puro (Vanilla).

---

aprenda-web/

## 🌐 Como Executar Localmente

1. Faça o clone ou baixe este repositório:
   ```bash
   git clone https://github.com/jennial-code/aprenda-web.git
   ```
2. Abra o arquivo `index.html` diretamente no seu navegador de preferência (Google Chrome, Edge, Firefox, etc.).

---

## 🚀 Publicando com GitHub Pages (Site Online Grátis)

Você pode hospedar este projeto gratuitamente no **GitHub Pages**:
1. No seu repositório no GitHub, vá em **Settings** (Configurações).
2. No menu lateral esquerdo, clique em **Pages**.
3. Em **Branch**, selecione `main` e a pasta `/ (root)`.
4. Clique em **Save**.
5. Aguarde alguns instantes e seu site estará no ar em: `https://jennial-code.github.io/aprenda-web/`
