Módulo 1

HTML — A Estrutura

HTML é o esqueleto de toda página web. Ele define o que aparece na tela: textos, imagens, links, formulários e muito mais.

01

Estrutura Básica do HTML

Todo documento HTML começa com uma estrutura básica. Pense nela como o "esqueleto" da página:

  • <!DOCTYPE html> — Diz ao navegador que é um documento HTML5
  • <html> — O elemento raiz que envolve tudo
  • <head> — Informações sobre a página (título, charset, etc.)
  • <body> — O conteúdo visível da página
💡 Toda tag que abre precisa fechar! Por exemplo: <p>texto</p>. As tags são como parênteses — sempre em pares.
Resultado
02

Títulos, Parágrafos e Formatação

O HTML tem 6 níveis de títulos (<h1> a <h6>) e tags para formatar texto:

  • <h1> — Título principal (o maior e mais importante)
  • <h2> a <h6> — Subtítulos em ordem decrescente
  • <p> — Parágrafo de texto
  • <strong> — Texto em negrito
  • <em> — Texto em itálico
  • <br> — Quebra de linha (não precisa fechar!)
Resultado
03

Links, Imagens e Listas

Conecte páginas com links, adicione imagens e organize informações com listas:

  • <a href="url"> — Cria um link clicável
  • <img src="url" alt="desc"> — Insere uma imagem
  • <ul> / <ol> — Lista não-ordenada (•) / ordenada (1, 2, 3…)
  • <li> — Cada item dentro da lista
💡 O atributo alt na imagem é essencial para acessibilidade — ele descreve a imagem para leitores de tela.
Resultado
04

Formulários e Inputs

Formulários permitem que o usuário interaja e envie dados. São a base de login, cadastro, pesquisas, etc:

  • <form> — Agrupa todos os campos do formulário
  • <input> — Campo de entrada (texto, email, senha, etc.)
  • <label> — Rótulo para o campo (melhora acessibilidade)
  • <select> — Menu dropdown de opções
  • <textarea> — Campo de texto longo
  • <button> — Botão clicável
Resultado
05

Tabelas e Semântica

Organize dados em tabelas e use tags semânticas para dar significado ao conteúdo:

  • <table>, <tr>, <th>, <td> — Tabela, linha, cabeçalho e célula
  • <header>, <main>, <footer> — Estrutura semântica da página
  • <nav> — Área de navegação
  • <section> / <article> — Seções e artigos do conteúdo

Módulo 2

CSS — O Estilo

CSS transforma páginas simples em experiências visuais incríveis. Ele controla cores, fontes, espaçamentos, layouts e animações.

06

Introdução ao CSS e Seletores

CSS significa Cascading Style Sheets. Ele aplica estilos ao HTML usando seletores:

  • Seletor de tag: p { ... } — estiliza todos os <p>
  • Seletor de classe: .destaque { ... } — estiliza elementos com class="destaque"
  • Seletor de ID: #titulo { ... } — estiliza o elemento com id="titulo"
  • Propriedades comuns: color, background, font-size, margin, padding
💡 Use a tag <style> dentro do <head> para escrever CSS diretamente no HTML. Em projetos reais, usamos arquivos .css separados.
Resultado
07

Box Model: Margin, Padding e Border

Todo elemento HTML é uma caixa. O Box Model define como ela ocupa espaço:

  • content — O conteúdo do elemento (texto, imagem, etc.)
  • padding — Espaço interno (entre conteúdo e borda)
  • border — A borda ao redor do elemento
  • margin — Espaço externo (entre o elemento e outros)
Resultado
08

Flexbox — Layouts Modernos

Flexbox é a forma mais prática de criar layouts. Ele alinha e distribui elementos automaticamente:

  • display: flex — Ativa o Flexbox no container
  • justify-content — Alinha no eixo horizontal (center, space-between, etc.)
  • align-items — Alinha no eixo vertical
  • gap — Espaço entre os itens
  • flex-direction: column — Muda a direção para vertical
Resultado
09

Cores, Gradientes e Sombras

CSS oferece muitas formas de trabalhar com cores e efeitos visuais:

  • Cores nomeadas: red, blue, coral, etc.
  • Hexadecimal: #ff6b6b, #6c5ce7
  • RGB/RGBA: rgba(108, 92, 231, 0.5) — com transparência!
  • Gradientes: linear-gradient() — mistura de cores
  • Sombras: box-shadow e text-shadow
Resultado
10

Transições e Animações

Dê vida às suas páginas com transições suaves e animações CSS:

  • transition — Anima mudanças de propriedade (hover, click, etc.)
  • transform — Move, gira, escala ou inclina elementos
  • @keyframes — Define animações personalizadas frame a frame
  • animation — Aplica a animação ao elemento
💡 Passe o mouse sobre os elementos no resultado para ver as transições em ação!
Resultado
11

Design Responsivo

Sites precisam funcionar bem em qualquer tamanho de tela. Para isso usamos:

  • @media queries — Aplica estilos diferentes para tamanhos de tela diferentes
  • Unidades relativas: %, vw, vh, rem, em
  • max-width — Limita a largura máxima
  • flex-wrap: wrap — Permite que itens quebrem linha
💡 Redimensione a janela de resultado para ver a media query em ação! Em telas menores, o layout muda automaticamente.

Módulo 3

JavaScript — A Interação

JavaScript torna a página interativa. Ele responde a cliques, muda conteúdo, calcula valores e muito mais — tudo em tempo real.

12

Variáveis e Tipos de Dados

Variáveis armazenam valores que o programa usa. Pense nelas como "caixas com nome":

  • let — Declara uma variável que pode mudar
  • const — Declara uma constante (não muda)
  • String: texto entre aspas → "Olá"
  • Number: números → 42, 3.14
  • Boolean: verdadeiro ou falso → true, false
  • Array: lista de valores → [1, 2, 3]
💡 Usamos document.write() nos exemplos para mostrar texto na página. Em projetos reais, preferimos manipular o DOM (próximas lições!).
Resultado
13

Condicionais e Loops

Condicionais permitem tomar decisões. Loops repetem ações:

  • if / else if / else — "Se... senão se... senão"
  • for — Repete um bloco um número definido de vezes
  • while — Repete enquanto uma condição for verdadeira
  • Comparações: === (igual), !== (diferente), >, <, >=, <=
Resultado
14

Funções

Funções são blocos de código reutilizáveis. Elas recebem dados, processam e retornam resultados:

  • function nome(params) { } — Declara uma função
  • return — Retorna um valor da função
  • Arrow function: const soma = (a, b) => a + b — Sintaxe moderna e curta
  • Funções podem ser passadas como argumento para outras funções!
Resultado
15

Eventos e Interatividade

Eventos são ações do usuário (clique, digitação, hover) que o JavaScript pode detectar e responder:

  • onclick — Quando o usuário clica
  • oninput — Quando digita em um campo
  • onmouseover / onmouseout — Hover do mouse
  • addEventListener() — Forma moderna de ouvir eventos
💡 Clique nos botões e interaja com os campos no resultado para ver os eventos em ação!
Resultado
16

Manipulação do DOM

O DOM (Document Object Model) é a representação da página HTML como objetos JavaScript. Você pode criar, modificar e remover elementos dinamicamente:

  • document.getElementById() — Busca um elemento pelo ID
  • document.querySelector() — Busca com seletor CSS
  • .textContent / .innerHTML — Muda o conteúdo
  • .style — Muda o estilo CSS via JS
  • document.createElement() — Cria um novo elemento
  • .appendChild() — Adiciona um elemento filho
Resultado
17

Objetos e JSON

Objetos agrupam dados relacionados em uma única estrutura. JSON é o formato padrão para trocar dados na web:

  • { chave: valor } — Sintaxe de objetos em JS
  • objeto.propriedade — Acessa um valor
  • JSON.stringify() — Converte objeto para texto JSON
  • JSON.parse() — Converte texto JSON para objeto
